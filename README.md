# 🍵 Spill the Tea
> 

Spill the tea는 짤 기능, 소설화 기능, 음성 출력 기능 등을 이용하여 재미있게 썰을 풀고 게시하며 소통 할 수 있는 반응형 웹 커뮤니티입니다.

## 🎯 서비스 의도
디지털 콘텐츠 창작 시장의 성장과 함께, 20대는 다양한 게시물을 공유하며 자신의 경험과 생각을 표현하고 있습니다. 이러한 흐름을 바탕으로, 누구나 자신의 이야기를 보다 쉽고 재미있게 풀어낼 수 있는 서비스를 기획했습니다.

게시글 작성 시 짤 첨부와 소설화 기능을 제공해 표현의 재미를 높이고, 댓글을 통해 사용자 간 소통이 자연스럽게 이어지도록 구성했습니다. 또한 게시글을 더욱 편리하게 즐길 수 있도록 음성 나레이션 기능을 제공했습니다.

이를 통해 Spill the Tea가 지향하는 **“즐겁게 썰을 풀고, 함께 이야기할 수 있는 서비스”​**라는 목적을 구현하고자 했습니다.
